# 요구사항: 집중력 비서 MVP

## 소개
업무 연락이 메일 4종(Gmail·네이버 메일·네이버웍스·아웃룩), 업무용 카카오톡·슬랙, 통화 녹음(에이닷), AI 회의록(클로바노트·Tiro·다글로)에 흩어진 사용자가 하루 집중력을 '판단'에만 쓰도록 돕는 웹앱이다. 해커톤 MVP는 가상 인물의 하루치 샘플 연락으로 핵심 흐름(모으기 → 오늘의 한 장 → 답장 초안 → 통화·회의 점검)을 끝까지 보여준다.

## 요구사항 1: 흩어진 연락을 한 화면에 모으기
**사용자 스토리:** 여러 앱을 쓰는 사용자로서, 모든 업무 연락을 한 화면에서 보고 싶다. 그래야 앱을 하나씩 열어 확인하지 않아도 된다.

### 인수 조건
1. WHEN 앱을 열면 THE SYSTEM SHALL `data/demo.json`의 모든 연락을 시간순으로 보여준다.
2. THE SYSTEM SHALL 각 연락에 출처(Gmail·네이버 메일·네이버웍스·아웃룩·카카오톡·슬랙·에이닷 통화·클로바노트·Tiro·다글로)를 글자 배지로 표시한다.
3. WHEN 사용자가 출처 필터를 누르면 THE SYSTEM SHALL 그 출처의 연락만 보여준다.
4. WHEN 사용자가 '사람별로 보기'를 켜면 THE SYSTEM SHALL 같은 사람의 연락을 채널과 관계없이 한 묶음으로 보여준다.

## 요구사항 2: 오늘의 한 장
**사용자 스토리:** 집중력이 한정된 사용자로서, 오늘 내가 결정할 것만 근거와 함께 한 장으로 받고 싶다. 그래야 원문을 다시 읽지 않고 바로 처리할 수 있다.

### 인수 조건
1. WHEN 앱을 열면 THE SYSTEM SHALL '오늘의 한 장'을 첫 화면으로 보여준다.
2. THE SYSTEM SHALL 각 항목에 유형(충돌·잊힌 약속·답 안 한 질문·빈칸), 조언 문장, 관련 인물, 무게(2분·생각 필요·나중)와 집중력 점수를 표시한다.
3. THE SYSTEM SHALL 각 항목에 근거 원문을 하나 이상 연결하고, WHEN 사용자가 근거를 누르면 THE SYSTEM SHALL 원문 전체를 보여준다.
4. THE SYSTEM SHALL 오늘 쓸 집중력 합계를 하루 예산(100) 대비 막대로 보여준다.
5. THE SYSTEM SHALL 바로 처리해야 하는 항목(오늘 마감, 두 채널 이상 연락, 약속 기한 임박)을 맨 위에 '바로' 표시와 함께 둔다.
6. THE SYSTEM SHALL 오늘 넘겨도 되는 연락을 이유와 함께 별도 목록으로 보여준다.

## 요구사항 3: 답장 초안과 말투 이유
**사용자 스토리:** 답장 말투가 고민되는 사용자로서, 상대와 상황에 맞는 초안을 고르고 싶다. 그래야 첫 문장부터 고민하지 않는다.

### 인수 조건
1. WHEN 사용자가 항목의 '답장 초안'을 누르면 THE SYSTEM SHALL `정중하게`와 `간결하게` 두 초안을 보여준다.
2. THE SYSTEM SHALL 초안마다 받는 사람, 채널, "왜 이 말투인지" 한 줄을 함께 보여준다.
3. WHEN 사용자가 '복사'를 누르면 THE SYSTEM SHALL 초안을 클립보드에 복사하고 "원래 앱에서 보내세요"라고 알린다.
4. THE SYSTEM SHALL 어떤 메시지도 직접 보내지 않는다.

## 요구사항 4: 통화·회의 점검
**사용자 스토리:** 통화와 회의가 많은 사용자로서, 방금 대화에서 놓친 것이 무엇이고 다른 채널과 어떻게 이어지는지 알고 싶다. 그래야 녹음을 다시 듣지 않아도 된다.

### 인수 조건
1. THE SYSTEM SHALL 샘플 통화·회의마다 정해진 것, 안 정해진 것, 내 약속(기한), 상대 요청, 다른 채널과의 연결을 보여준다.
2. WHEN 사용자가 전사 텍스트를 붙여넣고 '점검'을 누르면 THE SYSTEM SHALL 약속, 질문, 미정 사항, 날짜·시각 표현을 찾아 보여준다.
3. THE SYSTEM SHALL 붙여넣은 텍스트를 브라우저 밖으로 보내지 않는다.
4. IF 붙여넣은 텍스트가 비어 있으면 THEN THE SYSTEM SHALL 점검하지 않고 안내 문구를 보여준다.
5. WHEN 줄이 `화자: 내용` 형식이면 THE SYSTEM SHALL 화자가 '나'인 약속을 내 약속으로, 나머지를 상대 약속으로 나눈다.

## 요구사항 5: 신뢰와 안전
**사용자 스토리:** 업무 연락을 맡기는 사용자로서, 비서가 지어낸 내용이 없는지 확인하고 싶다.

### 인수 조건
1. THE SYSTEM SHALL 샘플 데이터가 가상이라는 것과 분석 결과를 만든 방법을 화면에 밝힌다.
2. THE SYSTEM SHALL 근거 원문에 없는 사실을 조언에 쓰지 않는다 (데이터 작성 규칙: `.kiro/steering/assistant-rules.md`).
3. THE SYSTEM SHALL API 키, 비밀번호, 실제 개인 정보를 레포에 포함하지 않는다.

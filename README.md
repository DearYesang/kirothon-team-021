# 집중력 비서

업무 연락이 메일·카카오톡·슬랙·통화 녹음·AI 회의록에 흩어진 대학원생과 직장인이 매일 앱을 돌며 확인하고, 답장 첫 문장을 고민하고, 통화에서 한 약속을 잊는 불편을 하루 한 장의 '결정할 것' 목록과 답장 초안으로 줄이는 웹앱입니다.

**Demo:** [https://dearyesang.github.io/kirothon-team-021/](https://dearyesang.github.io/kirothon-team-021/) (설치 없이 바로 열립니다. 가상 인물의 하루치 샘플 연락으로 동작합니다.) · 데모 영상(83초, 내레이션·자막): [https://youtu.be/6ZeX0G_CtTU](https://youtu.be/6ZeX0G_CtTU)

## 1. 문제 정의

### 대상 사용자
메일(Gmail·네이버 메일·네이버웍스·아웃룩)과 업무용 카카오톡·슬랙을 함께 쓰고, 통화 녹음 전사(에이닷)와 AI 회의록(클로바노트·Tiro·다글로)까지 쓰는 대학원생·연구원·직장인입니다. 특히 지도교수, 상사, 거래처, 외부 기관처럼 말투를 신경 써야 하는 상대와 하루에도 여러 번 연락을 주고받는 사람이 대상입니다.

### 문제 상황
- **누가:** 연구실 산학과제 실무를 맡은 대학원생 (데모 속 가상 인물 한지우)
- **어떤 상황에서:** 같은 일에 대한 연락이 여러 앱으로 나뉘어 들어옵니다. 데모 속 11월 12~13일에는 지도교수의 아웃룩 메일 질문, 협력사 과장의 네이버웍스 메일(일정을 당기자는 요청)과 카톡 재촉, 에이닷 통화에서 한 약속, 클로바노트·Tiro·다글로 회의록에 적힌 날짜가 섞여 들어옵니다.
- **무엇이 불편한지:** 시간보다 집중력이 먼저 바닥납니다. 집중력이 새는 곳은 네 군데입니다.
  1. **앱 확인:** 놓친 연락이 있을까 봐 메일 4개, 메신저 2개, 통화 녹음, 회의록 앱을 하나씩 열어 봅니다.
  2. **원문 다시 읽기:** 무엇을 해야 하는지 알려고 긴 메일, 슬랙 스레드, 통화 전사를 다시 읽습니다.
  3. **답장 첫 문장 고민:** 교수님, 상사, 거래처마다 호칭과 존댓말 수준이 달라 첫 문장에서 오래 멈춥니다.
  4. **약속 기억하기:** 통화에서 "오늘 중으로 보내드릴게요"라고 한 말, 회의에서 정하지 못한 시간과 장소를 따로 기억해야 합니다.

  그래서 정작 판단이 필요한 일(예: 회의에서 20일로 정한 중간보고를 19일로 당기자는 메일이 왔을 때 어떻게 답할지)에 쓸 집중력이 남지 않습니다.

### 기존 방식과 한계

| 지금 하는 방법 | 한계 |
|---|---|
| 앱마다 따로 열어 확인 | 같은 사람이 메일, 카톡, 통화로 같은 일을 연락해도 한 묶음으로 보이지 않습니다. 확인할 때마다 하던 일이 끊깁니다. |
| 각 앱의 AI 요약 (메일 요약, 회의록 요약, 통화 요약) | 그 앱 안의 내용만 요약합니다. 통화에서 한 약속을 메일로 이행했는지, 회의록 날짜가 메일과 다른지는 알려 주지 않습니다. |
| ChatGPT 같은 챗봇에 복사해 붙여넣기 | 매번 원문을 모아 복사해야 하고, 대화가 끝나면 사람과 약속의 맥락이 끊깁니다. 말투 기준도 매번 다시 설명해야 합니다. |
| 머릿속이나 메모장에 기억 | 기억해 두는 일 자체가 집중력을 씁니다. |

### 목표
시간이 아니라 **집중력**을 아끼는 것이 목표입니다. 집중력이 새는 네 곳을 하나씩 막습니다.

- **앱 확인 → 한 화면:** 여러 앱을 돌지 않고 '오늘의 한 장'에서 오늘 결정할 것만 봅니다.
- **원문 다시 읽기 → 근거 연결:** 모든 조언에 근거 원문(출처·시각)을 붙여, 누르면 원문이 바로 열립니다.
- **첫 문장 고민 → 초안 두 개:** 상대·채널·상황에 맞춘 `정중하게`와 `간결하게` 초안을 말투 이유와 함께 줍니다. 보내는 것은 사용자가 원래 앱에서 합니다.
- **약속 기억하기 → 장부 맞추기:** 통화·회의에서 나온 내 약속, 상대 요청, 미정 사항을 꺼내 메일·메신저와 맞춰 봅니다.
- 하루 집중력 예산을 100으로 두고, 오늘 할 일의 무게(2분·생각 필요·나중)를 숫자로 보여 줍니다.

해커톤 기간의 목표는 가상 인물의 하루치 연락으로 이 흐름을 처음부터 끝까지 보여 주는 공개 웹앱을 만드는 것입니다.

| **오늘의 한 장:** 충돌·잊힌 약속·답 안 한 질문·빈칸 네 유형의 복합 조언 카드. 급한 항목은 '바로' 표시와 함께 맨 위에 둡니다. | 원문 다시 읽기, 약속 기억하기 | `src/app.js`의 `renderOnePage`·`renderItemCard`·`sortItems`, `data/demo.json`의 `onePage`, 판단 규칙 `.kiro/steering/assistant-rules.md` 1절 |

## 3. 사용 시나리오

1. [데모 주소](https://dearyesang.github.io/kirothon-team-021/)를 엽니다. 첫 화면은 '오늘의 한 장'입니다. 맨 위에 가상 인물 한지우(대학원 석사과정, 산학과제 실무 담당)의 11월 13일과 "오늘 결정할 것 6개 · 예상 집중력 55 / 100", 집중력 막대가 보입니다.
2. 맨 위의 '바로' 카드 세 개부터 읽습니다. 첫 카드 "전처리 결과 요약: 오늘 보내기로 한 약속"은 에이닷 통화에서 박민재 과장에게 "오늘 중으로 전처리 결과 요약 보내드릴게요"라고 했는데 보낸 기록이 없고, 15:40에 과장이 카톡으로 다시 물었고, 요약은 이미 공유 폴더에 있다(슬랙)는 것을 묶어 "메일로 보내고 카톡으로 한 줄 알리면 끝"이라고 알려 줍니다. 조언은 모두 "무슨 일 → 왜 문제 → 무엇을 하면 되는지" 순서입니다.
3. 카드의 근거 칩(예: "에이닷 통화 · 11/13 10:32")을 누르면 원문 전체가 열리고 인용한 문장이 강조됩니다. 다른 앱을 열지 않고 사실을 확인합니다.
4. '답장 초안'을 눌러 `정중하게`와 `간결하게`를 바꿔 보고, "왜 이 말투인지"를 읽은 뒤 `복사`를 누릅니다. 원래 앱(메일, 카톡, 슬랙)에 붙여 넣어 보냅니다.
5. '흩어진 연락' 탭에서 '사람별로 보기'를 켜면, 같은 사람이 메일·카톡·통화로 보낸 연락이 한 묶음으로 보입니다.
6. '통화·회의 점검' 탭에서 샘플 통화의 내 약속과 기한, 이어지는 메일을 확인합니다. 아래 '직접 붙여넣어 점검하기'에서 `예시 넣기`와 `점검`을 누르거나 내 통화 전사를 붙여 넣으면 약속·질문·미정·날짜가 목록으로 나옵니다. 입력한 내용은 브라우저 밖으로 나가지 않습니다.

## 5. 차별점

| 비교 대상 | 그쪽의 방식 | 집중력 비서 |
|---|---|---|
| Meta Muse (2026년 9월 8일 출시) | 먼저 나서서 일을 처리하는 개인 AI 에이전트 | 대신 처리하지 않습니다. 판단할 것을 모으고 초안까지만 씁니다. 보내는 것은 사용자가 원래 앱에서 합니다. |
| OpenAI dots | 연결된 앱을 읽기 전용으로 살펴 놓친 것을 알려 주는 상시 에이전트 | 놓친 것을 알리는 데서 그치지 않고, 사람·약속·일 장부 세 개를 맞춰 충돌, 잊힌 약속, 답 안 한 질문, 빈칸을 찾습니다. 한국 업무 도구(네이버 메일·네이버웍스·카카오톡·에이닷·클로바노트·다글로·Tiro)와 한국식 호칭·존댓말이 기본입니다. |
| 각 앱의 AI 요약 | 그 앱 안의 내용만 요약 | 여러 채널을 묶은 복합 조언을 주고, 조언마다 근거 원문을 연결합니다. |
| ChatGPT에 복사해 붙여넣기 | 매번 복사, 대화가 끝나면 맥락이 끊김, 말투 기준을 매번 설명 | 사람과 약속을 장부로 이어서 봅니다. 말투 규칙은 `.kiro/steering/assistant-rules.md`에 고정돼 있고, 붙여넣기 점검은 브라우저 밖으로 나가지 않습니다. |

공통으로 다른 점은 세 가지입니다.
- **집중력 예산:** 하루 100을 기준으로 2분·생각 필요·나중 무게를 매겨, 오늘 무엇을 미룰지 정할 수 있게 합니다.
- **근거 원문:** 모든 조언에 출처와 시각이 달린 원문이 붙습니다. 원문에 없는 사실은 쓰지 않고, 기록이 없으면 "기록 없음"이라고 씁니다.
- **초안까지만:** 메시지를 직접 보내지 않으므로 잘못 보낼 위험이 없습니다.

## 6. 설치와 실행

설치할 의존성이 없습니다. 빌드 도구나 외부 라이브러리 없이 HTML, CSS, JavaScript만 씁니다. 가장 쉬운 방법은 위 **Demo** 주소를 브라우저로 여는 것입니다. 내 컴퓨터에서 실행하려면 아래를 따라 하세요. (브라우저와 python3만 있으면 됩니다.)

```bash
# 1. 의존성 설치
# 설치할 것이 없습니다. 레포만 내려받습니다.
git clone https://github.com/DearYesang/kirothon-team-021.git
cd kirothon-team-021

# 2. 실행
python3 -m http.server 8000 --bind 127.0.0.1
# 브라우저에서 http://127.0.0.1:8000 을 엽니다. (macOS 터미널에서는 open http://127.0.0.1:8000)
```

`index.html` 파일을 더블클릭해서 열면 동작하지 않습니다. 화면이 `data/demo.json`을 불러오기 때문에 위처럼 로컬 서버로 열어야 합니다.

## 7. 테스트

Node.js 18 이상이 필요합니다. 설치할 패키지는 없고 Node 내장 테스트 러너(`node --test`)를 씁니다.

```bash
npm test
```

- `tests/engine.test.js`: 붙여넣기 점검 엔진(`src/engine.js`)을 확인합니다. 타임스탬프를 떼고 화자와 내용 나누기, 내 약속과 기한 찾기(예: "오늘 중", "내일 오전"), 상대 약속과 "기한 없음", 부탁·감사 인사를 약속으로 보지 않기, 물음표와 의문 어미로 질문 찾기, 미정 사항 찾기, 날짜·시각 표현의 중복 제거, 소수점을 자르지 않는 문장 나누기, 빈 입력, 6줄짜리 통화 전사 전체 점검.
- `tests/data.test.js`: 샘플 데이터(`data/demo.json`)를 확인합니다. 출처 10종과 라벨, id 중복 없음, 모든 personId·messageId·draftIds·to가 실제 대상을 가리키는지, 모든 근거 인용 문장이 원문에 그대로 들어 있는지, 초안이 `정중하게`·`간결하게` 두 개인지, 첫 줄(headline)의 항목 수와 집중력 합계가 실제 값과 같은지, `예시 넣기` 문장에서 엔진이 약속·질문·날짜를 찾는지.
- 화면은 데모 주소에서 세 탭, 근거 원문 창, 초안 복사, 붙여넣기 점검을 직접 눌러 확인합니다.
